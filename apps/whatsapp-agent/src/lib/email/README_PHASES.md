# Email delivery phases

- E0 Foundation: contracts, provider registry, runtime gates, sender rules, architecture docs.
- E1 Connections: Gmail OAuth, encrypted refresh/access token persistence, connection health, multi-sender discovery/default selection.
- E2 Template Studio: CRUD/versioning, rich editor, media/attachments, preview/test, approval lifecycle.
- E3 Manual Send: composer, sender switching, CC/BCC/Reply-To, dry-run/internal allowlist, outbound logs.
- E4 Automation: NEW_LEAD and CRM triggers, SEND_EMAIL, idempotent queues, wait/condition, message/template control.
- E5 Inbound: Gmail watch/history, threads, replies, attachments, unified inbox.
- E6 Campaigns: segments, sequences, throttling, frequency caps, pause/resume/cancel.
- E7 Analytics: delivery/reply/bounce metrics, sender health, automation/template conversion.
- E8 Additional Providers: Microsoft 365, Brevo/SES/Resend according to business need.
